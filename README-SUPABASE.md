# SergysLand — чат, отзывы и панель разработчика

## 1. Создать Supabase
1. Открой https://supabase.com/dashboard
2. Войди/зарегистрируй аккаунт.
3. Нажми **New project**.
4. Название: `sergysland`.
5. Выбери организацию, задай пароль базы данных и регион.
6. Дождись окончания создания проекта.

## 2. Создать базу
1. Открой проект.
2. Перейди **SQL Editor**.
3. Создай новый запрос.
4. Скопируй весь файл `supabase.sql` из этого архива.
5. Нажми **Run**.

## 3. Создать аккаунт разработчика
1. В проекте открой **Authentication -> Users**.
2. Создай пользователя с email и паролем.
3. Скопируй его email.
4. В SQL Editor выполни:

insert into public.staff_members(user_id,email,role)
select id,email,'admin' from auth.users where lower(email)=lower('ТВОЙ_EMAIL');

Вместо `ТВОЙ_EMAIL` укажи свой email.

## 4. Получить URL и Publishable key
В проекте открой **Connect** (или API/Project Settings, если интерфейс показывает старое меню).
Скопируй:
- Project URL
- Publishable key

Открой `supabase-config.js` и вставь их сюда:

const SUPABASE_URL = "https://...supabase.co";
const SUPABASE_PUBLISHABLE_KEY = "...";

Не вставляй в сайт `service_role` или другой секретный серверный ключ. Для браузера используется publishable/anon key, а доступ защищается RLS.

## 5. Загрузить сайт
Загрузи содержимое архива в репозиторий GitHub Pages вместо старой версии.
После публикации:
- `#support` — чат;
- `#reviews` — голоса;
- `#developer` — панель разработчика.

## 6. Добавить сотрудников
Сначала сотрудник должен существовать в **Authentication -> Users**.
Затем войди в панель разработчика как admin -> **Сотрудники** -> укажи его email -> выбери роль -> добавить.

`staff` может отвечать и модерировать отзывы.
`admin` дополнительно управляет сотрудниками.

## Важно
Текущая версия чата — общая публичная лента поддержки: посетители видят вопросы и ответы. Не размещайте в ней пароли, адреса, телефоны и другие личные данные.
